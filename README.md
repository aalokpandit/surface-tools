# Surface Pro 4 Tools
A collection of utilities to optimize the Linux experience on the Surface Pro 4.

## Media Tools
- `bridge_camera.sh`: Toggleable GStreamer bridge for Front/Rear cameras via v4l2loopback.
- `restore_surface_media.sh`: Restoration script for IPU3 colors and PipeWire audio.

## Future Evolution
This repository is intended to house further hardware optimizations (touch, power, etc.) as they are developed.
